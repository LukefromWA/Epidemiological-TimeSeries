# Epidemiological-TimeSeries
Time-series analysis of dengue in Bangladesh (2008–2021), linking climate variables to outbreaks. Combines SSA, MSSA, SARIMAX, and VARIMA for trend and seasonality detection, lagged effects, and forecasting. Highlights hybrid modeling for data-driven early-warning insights. 

Project Features:
	•	Decomposition of trends and seasonality using SSA and MSSA
	•	Lagged effect analysis of temperature and rainfall on dengue cases
	•	Hybrid models combining MSSA residuals with SARIMAX
	•	Forecasting dengue outbreaks up to 36 months

Data:
	•	Dengue incidence and climate data from Bangladesh (2008–2021)
	•	Monthly and daily time series

Skills & Techniques:
Time-series modeling, R programming, SSA/MSSA, SARIMAX, VARIMA, cross-correlation analysis, forecasting, hybrid modeling
